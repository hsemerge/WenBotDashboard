Before it works
The two steps this page can't do for you
1 · The streamer points their DNS at Netlify. A CNAME on www to wenbot.netlify.app, and an ALIAS/A record on the bare domain.
2 · Add the domain in Netlify (Site settings → Domain management) so it gets an HTTPS certificate. Without this the browser shows a certificate warning.
Then this mapping takes effect on the next deploy — it's compiled into the edge router at build time so it costs nothing on every page load.
